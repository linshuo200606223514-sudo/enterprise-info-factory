# 企业信息收集系统 设计文档

**日期**: 2026-05-09
**版本**: v1.0
**状态**: 已批准，等待实现

---

## 目标

构建一个企业信息收集系统，作为"AI自动开发企业应用工厂"的第一个模块。

**核心价值**: 通过多数据源搜索和AI分析，从公开渠道快速构建企业画像，为后续元模型配置提供数据基础。

**使用方**: 内部团队，在拜访企业前快速了解背景

---

## 系统架构

```
┌─────────────────────────────────────────────────────┐
│                     输入层                           │
│            企业名称 / 关键词 / 行业                   │
└─────────────────────────┬───────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│                   数据源层（按优先级）                  │
│  ① 百度搜索 → 网页文本提取                           │
│  ② 天眼查/企查查 → 工商信息 API                      │
│  ③ 行业网站 → 业务信息                               │
│  ④ 社交媒体 → 舆情/口碑                             │
└─────────────────────────┬───────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│                   处理层                             │
│  Python: 爬虫/搜索/抓取                              │
│  AI分析: LLM提取结构化实体（实体+关系+标签）           │
└─────────────────────────┬───────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────┐
│                   输出层                             │
│  ① JSON本地存储（原始数据+结构化数据）                │
│  ② Markdown报告（可读的企业画像）                      │
│  ③ 元模型配置（可导入元系统的YAML/JSON参数文件）       │
└─────────────────────────────────────────────────────┘
```

## 核心数据维度

| 维度 | 来源 | 说明 |
|------|------|------|
| **基础工商** | 天眼查/企查查API | 注册资本、地址、股东、成立时间 |
| **业务范围** | 百度搜索+官网 | 产品/服务、主营市场、客户类型 |
| **组织规模** | 招聘网站+搜索 | 人数、团队结构、部门划分 |
| **行业特征** | 行业网站+新闻 | 所在赛道、竞争格局、发展动态 |
| **管理痛点** | AI推断（基于行业典型问题） | 推测可能的痛点 |
| **舆情评价** | 社交媒体/新闻 | 口碑、问题投诉、新闻报道 |

## 技术分工

## 数据源详细说明

### 优先级1: 百度搜索
- **工具**: Playwright + baidu-search skill
- **输入**: 企业名称关键词
- **输出**: 网页标题、URL、摘要
- **后续**: 深度抓取关键页面正文

### 优先级2: 天眼查/企查查
- **工具**: 官方API或页面抓取
- **数据**: 工商信息、股东信息、注册资本、成立日期
- **注意**: 部分数据需要登录账号

### 优先级3: 行业网站
- **工具**: Playwright爬虫
- **数据**: 业务描述、产品信息、行业动态
- **示例**: 行业黄页、B2B平台、企业官网

### 优先级4: 社交媒体
- **工具**: 微信搜索、抖音搜索、小红书搜索
- **数据**: 用户评价、口碑、投诉、新闻报道

```yaml
  - order_management
  - production_scheduling
  - inventory_control

  entities: [...]
  workflows: [...]
```

## 风险和注意事项

1. **数据合规**: 只收集公开信息，不要爬需要登录的数据
2. **频率控制**: 避免短时间内大量请求被封IP
3. **API成本**: AI分析需要消耗token，控制调用次数
4. **增量更新**: 支持增量收集，不要重复抓取未变化的数据
