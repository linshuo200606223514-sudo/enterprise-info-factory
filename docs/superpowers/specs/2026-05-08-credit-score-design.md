# 信用评分与风险标签设计文档

> **状态：** 已批准

## 1. 目标

为AI企业信息工厂添加信用评分元能力，基于多源工商数据（企查查、爱企查、启信宝、天眼查）生成标准化信用评分和风险标签，帮助东社造纸厂评估客户信用等级，降低坏账风险。

## 2. 架构概览

```
api/services/
├── creditScorer.js     # 新增：独立信用评分服务
└── dataMerger.js       # 现有：数据合并

server/routes/
└── enterprise.js       # 修改：增加 /credit-score/:companyName 端点
```

信用评分作为独立服务，不依赖采集流程，可单独调用或批量重评。

## 3. 评分维度

| 维度 | 权重 | 数据来源 | 说明 |
|------|------|----------|------|
| 基础工商 | 20% | 登记状态、成立年限、注册资本 | 经营稳定性 |
| 司法风险 | 30% | 被执行人、失信人、行政处罚 | 信用历史 |
| 经营状态 | 25% | 年营收、纳税人资质、员工规模 | 经营能力 |
| 变更记录 | 15% | 法人变更、资本变更、地址迁移 | 稳定性信号 |
| 负面舆情 | 10% | 新闻舆情（待扩展） | 市场口碑 |

## 4. 评分等级

| 等级 | 分值区间 | 标签颜色 | 说明 |
|------|----------|----------|------|
| A | 80-100 | 绿色 | 优质客户，低风险 |
| B | 60-79 | 蓝色 | 良好客户，轻微关注 |
| C | 40-59 | 黄色 | 中等客户，适度关注 |
| D | 20-39 | 橙色 | 高风险客户，谨慎合作 |
| E | 0-19 | 红色 | 极高风险，建议拒绝 |

## 5. 风险标签

系统自动打标，不占评分权重：

| 标签 | 触发条件 |
|------|----------|
| `失信` | 存在失信被执行人记录 |
| `老赖` | 存在失信人记录 |
| `经营异常` | 经营状态非"存续"或"在业" |
| `欠税` | 存在税务异常记录 |
| `资本实缴异常` | 注册资本与实缴差距大（需财务数据） |
| `法人频繁变更` | 近2年法人变更≥2次 |
| `地址频繁变更` | 近2年地址变更≥2次 |
| `新设企业` | 成立年限 < 1年 |

## 6. API 设计

### 6.1 信用评分查询

```
GET /api/credit-score/:companyName
```

**成功响应：**
```json
{
  "success": true,
  "data": {
    "company_name": "客户公司名称",
    "credit_score": 75,
    "credit_grade": "B",
    "risk_tags": ["法人频繁变更"],
    "dimensions": {
      "basic": { "score": 85, "max": 100 },
      "judicial": { "score": 60, "max": 100 },
      "operation": { "score": 70, "max": 100 },
      "changes": { "score": 50, "max": 100 },
      "sentiment": { "score": null, "max": 100 }
    },
    "summary": "信用良好，法人变更需关注",
    "generated_at": "2026-05-08T12:00:00Z"
  }
}
```

**错误响应：**
```json
{
  "success": false,
  "error": "未找到企业数据，请先执行采集"
}
```

### 6.2 批量信用评分

```
POST /api/credit-score/batch
Content-Type: application/json

{
  "companies": ["公司A", "公司B", "公司C"]
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "results": [
      { "company_name": "公司A", "credit_score": 75, "credit_grade": "B" },
      { "company_name": "公司B", "credit_score": 45, "credit_grade": "C" }
    ],
    "total": 2,
    "generated_at": "2026-05-08T12:00:00Z"
  }
}
```

## 7. 数据依赖

信用评分依赖以下数据源：

| 数据字段 | 必需 | 来源 |
|----------|------|------|
| company_name | 是 | 多源 |
| business_status | 是 | 多源 |
| establishment_date | 是 | 多源 |
| registered_capital | 是 | 多源 |
| employee_count | 否 | qichacha/qixin |
| annual_revenue | 否 | qixin/qichacha |
| taxpayer_type | 否 | qixin |
| judicial_risks | 是 | qichacha |
| administrative_penalties | 否 | 多源 |

## 8. 计分公式

```
最终评分 = Σ(维度得分 × 权重) / Σ权重

有效维度 = 权重 > 0 且 score !== null
若有效维度不足3个，返回 null 并提示数据不足
```
