## 📊 评分体系演进

### v1（旧体系）: Tavily 均分直接评分
```
status = good if avg_score > 0.5 and garbled == 0
```
- 问题：完全依赖 Tavily score，衡量的是「搜索相关性」而非「内容可用性」

### v2-v3: 多关键词扩展
- 每个维度支持 2-3 个关键词并行搜索
- 合并去重，保留最高分
- 数据量提升：玩家 8→30, 新闻 6→20, 竞品 6→20

### v4（新体系）: 内容可用性评分
```
quality_score =
    可用率 × 0.40 +
    高质量率 × 0.30 +
    域名多样性归一化 × 0.15 +
    Tavily均分 × 0.15

status:
    good    if quality_score >= 0.6
    warning if quality_score >= 0.4
    poor   otherwise
```

**4个指标定义**：
- **可用率** = (总结果 - 乱码 - 导航) / 总结果
- **高质量率** = score > 0.5 的结果比例
- **域名多样性** = 独立域名数量（归一化超过10个=满分）
- **Tavily均分** = Tavily API 返回的 score 平均值

## 🔬 Tavily Score 逆向分析结论

### 实测发现

| 实验 | 查询 | score范围 | 均值 | 标准差 |
|------|------|-----------|------|--------|
| 精确匹配 | "餐饮ERP" | 0.5493~0.9017 | 0.776 | 0.095 |
| 宽泛匹配 | "餐饮行业ERP数字化转型" | 0.9982~0.9999 | 0.9995 | 0.0005 |
| 英文对照 | "restaurant ERP" | 0.6857~0.8290 | 0.771 | - |

### 算法推断
```
score ≈ α·BM25(标题匹配) + β·向量相似度 + γ·域名权威性
```
- **BM25 主导**：精确词匹配 → 0.9999+，天花板效应明显
- **向量相似度**：6-8位小数支持连续计算
- **天花板效应**：查询越宽泛，score 越趋向 1.0，区分度消失

### 对 quality_score 的影响
- ✅ 可用率（40%）不受影响
- ✅ 域名多样性（15%）不受影响
- ⚠️ Tavily均分（15%）轻微影响
- ⚠️ 高质量率（30%）**受影响** — 0.5 阈值在天花板效应下失效
